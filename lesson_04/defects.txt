Дефекты
1. Ошибка в документации метода capitalize

Проблема: в примере использования допущена опечатка в названии метода: capitilize вместо capitalize.
Воспроизведение: посмотреть документацию метода.
Причина: опечатка при написании документации.
Рекомендация: исправить опечатку в докстринге: заменить capitilize на capitalize.

2. Неэффективная реализация метода trim

Проблема: метод удаляет пробелы по одному в цикле, что крайне неэффективно для строк с большим количеством пробелов.
Воспроизведение: utils.trim("                   long string").
Причина: использование цикла с removeprefix вместо встроенной оптимизации.
Решение: заменить на string.lstrip(" ") или просто string.lstrip() (если нужно удалять все пробельные символы).
Преимущества: lstrip работает за один проход по строке, а не за N проходов (где N — количество пробелов).

3. Избыточная логика в методе contains

Проблема: сложная и избыточная логика с обработкой исключений.
Код:

try:
    res = string.index(symbol) > -1
except ValueError:
    pass

Причина: метод index выбрасывает исключение, если подстрока не найдена, но сравнение с -1 бессмысленно — index никогда не возвращает -1.
Решение: использовать оператор in: return symbol in string.
Преимущества: код становится проще, читаемее и эффективнее.

4. Неочевидное поведение метода contains с пустой строкой

Проблема: utils.contains("test", "") возвращает True.
Причина: в Python пустая строка считается подстрокой любой строки.
Риск: может привести к ошибкам в логике программы, если разработчик не ожидает такого поведения.
Рекомендация:
либо явно указать это в документации;
либо добавить специальную обработку для пустой строки, если такое поведение нежелательно.

5. Избыточная проверка в методе delete_symbol

Проблема: перед вызовом replace выполняется проверка contains, что дублирует логику поиска подстроки.
Код: if self.contains(string, symbol): string = string.replace(symbol, "").
Причина: replace уже проверяет наличие подстроки и ничего не делает, если её нет.
Решение: убрать проверку contains, оставить только string.replace(symbol, "").
Преимущества: упрощение кода, повышение производительности (устранение двойного поиска).

6. Отсутствие обработки None и некорректных типов

Проблема: методы не проверяют входные параметры на None или некорректные типы.
Воспроизведение:
utils.capitalize(None) → TypeError;
utils.trim(None) → AttributeError.
Причина: отсутствие валидации входных данных.
Решение: добавить проверки на None в начале каждого метода.
Варианты обработки:
выбрасывать исключение с понятным сообщением;
возвращать значение по умолчанию (например, пустую строку).

7. Ограниченность метода trim

Проблема: метод удаляет только обычные пробелы (" "), но не другие пробельные символы (\t, \n, \r и т. д.).
Воспроизведение: utils.trim("\t\tSkyPro") → "\t\tSkyPro" (пробелы не удаляются).
Причина: жёсткая привязка к символу " ".
Решение: использовать string.lstrip() без аргументов — он удаляет все пробельные символы.

Исправленная версия класса
class StringUtils:
    """
    Класс с полезными утилитами для обработки и анализа строк
    """

    def capitalize(self, string: str) -> str:
        """
        Принимает на вход текст, делает первую букву заглавной
        и возвращает этот же текст.
        Пример: `capitalize("skypro") -> "Skypro"`
        """
        if string is None:
            raise ValueError("Input string cannot be None")
        return string.capitalize()

    def trim(self, string: str) -> str:
        """
        Принимает на вход текст и удаляет пробелы в начале, если они есть.
        Удаляет все пробельные символы (пробелы, табуляции и т. д.).
        Пример: `trim("   skypro") -> "skypro"`
        """
        if string is None:
            raise ValueError("Input string cannot be None")
        return string.lstrip()

    def contains(self, string: str, symbol: str) -> bool:
        """
        Возвращает `True`, если строка содержит искомый символ,
        и `False` — если нет.
        Параметры:
            `string` — строка для обработки
            `symbol` — искомый символ
        Примечание: пустая строка (`""`) считается содержащейся в любой строке.
        Пример 1: `contains("SkyPro", "S") -> True`
        Пример 2: `contains("SkyPro", "U") -> False`
        """
        if string is None or symbol is None:
            raise ValueError("Input parameters cannot be None")
        return symbol in string

    def delete_symbol(self, string: str, symbol: str) -> str:
        """
        Удаляет все вхождения подстроки из переданной строки.
        Параметры:
            `string` — строка для обработки
            `symbol` — подстрока для удаления
        Пример 1: `delete_symbol("SkyPro", "k") -> "SyPro"`
        Пример 2: `delete_symbol("SkyPro", "Pro") -> "Sky"`
        """
        if string is None or symbol is None:
            raise ValueError("Input parameters cannot be None")
        return string.replace(symbol, "")
